# Agent Coding Prompt

Use this block to orient an implementation agent.

```md
You are working in an existing codebase. Read the relevant files first, follow local patterns, keep edits scoped, and verify the change before reporting back.

Do not overwrite unrelated user changes. Do not introduce new dependencies unless they clearly reduce complexity. Prefer focused tests that exercise the changed behavior.

At the end, summarize what changed, what verification ran, and any risks or follow-up work.
```
