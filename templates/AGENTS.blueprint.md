# Agent Instructions

This project uses Blueprints as shared agent guidance.

## Priority

Project-specific instructions override shared Blueprints defaults.

## Use Blueprints

Start with the `blueprint` skill to select the smallest relevant guidance for the task.

Default references:

- Engineering standards: `standards/engineering.md`
- Testing playbook: `playbooks/testing.md`
- Review playbook: `playbooks/pr-review.md`
- Orchestration: `skills/blueprint-orchestrator/SKILL.md`
- Registry: `registry/skills.json`

## Reporting

When using Blueprints, report which skills, standards, or playbooks were used.
