# Repo Onboarding Playbook

Use this when bringing a project under Blueprints.

## Inspect

- repo remote and branch state
- existing agent guidance
- language and package managers
- build, test, lint, and typecheck commands
- CI and deploy configuration
- docs and ADRs
- issue tracker workflow
- security-sensitive files

## Decide

- Reference, copy, or hybrid install.
- Which standards apply.
- Which skills should be first-class for the project.
- Whether public repo safety needs cleanup.

## Install

- Add project guidance.
- Add `.blueprints/README.md` if copying local material.
- Add tool-specific examples only when useful.
- Keep project-specific rules above shared defaults.

## Verify

- Run the smallest available validation command.
- Confirm no secrets were introduced.
- Confirm guidance links resolve.
